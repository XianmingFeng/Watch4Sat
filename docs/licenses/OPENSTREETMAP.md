Watch4Sat's online map mode displays standard OpenStreetMap raster tiles.

- https://www.openstreetmap.org/copyright
- https://opendatacommons.org/licenses/odbl/1-0/

The complete ODbL 1.0 text retrieved from the official Open Data Commons plain
text link is preserved in `docs/licenses/ODBL-1.0.txt`.

The canonical on-map attribution is:

```text
© OpenStreetMap contributors
```

It must remain continuously visible on an OSM map. It must not be hidden behind
a control, timeout, or off-screen layout.

The standard tile service policy requires the canonical HTTPS tile URL,
visible attribution, a valid identifying User-Agent, normal HTTP caching, and
no bulk download or offline prefetch:

- https://operations.osmfoundation.org/policies/tiles/

Watch4Sat uses online tiles for interactive viewing and does not offer OSM
offline download. The separate embedded Offline world mode uses Natural Earth
and makes no OpenStreetMap request.
