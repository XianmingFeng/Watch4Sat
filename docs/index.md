# Watch4Sat

Watch4Sat is a standalone satellite pass tracker for Wear OS. The public
project repository contains the buildable application source, license material,
privacy policy, and version-specific source archives.

- [Privacy policy](https://xianmingfeng.github.io/Watch4Sat/privacy/)
- [1.0.0-rc.1 source](https://xianmingfeng.github.io/Watch4Sat/source/1.0.0-rc.1/)
- [Project repository](https://github.com/XianmingFeng/Watch4Sat)
